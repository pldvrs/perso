# cv/

Dépose ici ton CV sous le nom exact **`pierre-louis-divaris-cv.pdf`**.

C'est le fichier que visent les deux boutons du site : « Télécharger le CV » dans
le hero, et « CV (PDF) » dans le bandeau contact. Tant qu'il n'est pas là, les
deux liens renvoient une 404 — donc soit tu ajoutes le PDF avant de publier,
soit tu retires les deux liens de `index.html`.
